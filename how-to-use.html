Full Guide On How To Use

Please follow these guides and make sure that you have read our Terms and Conditions. We strongly condemn the misuse of this platform and its services.

1st Step

First-time users should click the Download button in the dashboard to install the agent app. Users who already have the APK installed and want to enroll should click the Open Installed Agent button in the dashboard.

2nd Step

In the agent app on your device, grant all permissions listed in the app by selecting each permission button. (Enable Device Admin, Enable Accessibility Control, Allow Camera and Microphone, Allow Location, Allow Phone and SIM Info, Allow File Access, Allow Owner Message Overlay, and Allow Background Running.) When you enable accessibility control, turn on only the accessibility control service; do not turn on the Aegis shortcut.

3rd Step

Subscription: Select a plan on the Subscription page before using the dashboard features, then choose your preferred payment method on the Checkout page.

Button Guide

  • Click around inside the enrolled device button to view device information, including the device details, current SIM phone number, and the five most recent call logs.
  • Click the Front Live Camera button to request a live camera session for the enrolled device. The session appears in the dashboard live view.
  • Click Locate to locate the enrolled device when location is enabled. The dashboard displays a Google Maps link so you can view directions.
  • Click Files to open a modal for browsing the enrolled device files. You can explore folders and view or export files. Refresh the dashboard after exporting to see the file.
  • Click Lock Phone to send a lock command to the enrolled device.
  • Click Ring to send a ring command to the enrolled device, even when it is in silent mode.
  • Click Disable to end the live camera session. You can start another session by clicking Front Live Camera again.

Lock Your Lost Device with Overlay Message

Type the message that you want the enrolled device to display as an overlay banner.

  • Click Show Owner Message to send the message to the enrolled device and display the overlay banner.
  • Click Hide Owner Message to hide the overlay banner from the device.
  • Keep Overlay On enabled to allow the owner message to appear after the device reconnects. Turn it off to prevent the agent from displaying the saved overlay message.

Recording Guide

This is to start, stop and save recording from the live streaming in the live section.
  • Click the Start button to record the live stream.
  • Click the Stop button to stop recording.
  • Click the Save button to save the recording.
  • Refresh the page to view or export the saved recording.

Settings

Go to the Settings page and scroll down to the owner overlay message section to edit it when needed.
